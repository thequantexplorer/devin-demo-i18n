# ridgeline-bikes-web

Marketing site for Ridgeline Bikes, a city bike rental shop. Next.js 15 App Router, TypeScript, plain CSS.

Pages: `/` (home), `/pricing` and `/about`. The header and footer live in `components/`.

```sh
npm install
npm run dev   # http://localhost:3000
npm test      # builds the site, starts it and checks every page in en, es and ja
```

The site is English only today, so most tests fail. See [DEVIN_DEMO.md](DEVIN_DEMO.md).
